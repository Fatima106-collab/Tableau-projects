# Sales Performance Dashboard – Tableau

An interactive Tableau dashboard analyzing sales performance for a company selling drones and robotics products across the MENA region.

## Overview
A comprehensive analysis of nearly 5,000 sales transactions across 7 countries (Morocco, Egypt, Syria, Algeria, Saudi Arabia, Kuwait, Iraq) between 2017 and 2019, with total revenue exceeding $6.9M.

## Tools
- **Tableau** for building interactive dashboards
- **Excel** as the data source

## Key Analyses
- Quantity sold by product
- Orders by country
- Orders by type (Wholesale / Retail)
- Order trends over time
- Sales by product category (Drones, Robot Kits, eBooks, etc.)
- Total cost and revenue breakdown
